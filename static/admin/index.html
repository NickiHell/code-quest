Code Quest

Веб-панель: статистика и управление (в браузере). Mini App живёт в Telegram.

Доступ

Введите ключ из переменной окружения ADMIN_API_KEY (отправляется в заголовке X-Admin-Key).

Режим ИИ

Активный бэкенд для квиза и проверки кода. В .env задаётся AI_BACKEND; здесь можно временно переопределить его (хранится в Redis, без перезапуска).
